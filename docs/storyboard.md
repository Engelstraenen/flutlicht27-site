## Regeln für die Videos
- Ein Clip pro Video-Kapitel, All-Intra, per Canvas gescrubbt (wie EISWERK).
- Startbild und Endbild jedes Clips stehen vor dem Rendern fest. Das Endbild ist das erste Bild der folgenden Grafik.
- Zoom und Kameraweg im Prompt ausdrücklich festlegen (Lehre aus EISWERK Açaí).
- Kein Text im Bild. Schrift kommt aus dem Code.
